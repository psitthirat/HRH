# ข้อมูล: แหล่งที่ใช้ คุณภาพ และสิ่งที่ยังต้องขอ (ฉบับรวม, สถานะ 15 ต.ค. 2569)

เอกสารนี้รวมสามเรื่อง ได้แก่ catalog ข้อมูล, การประเมินความพร้อมของข้อมูล และคำขอข้อมูลของบทที่ 4–5
- path ของแหล่งข้อมูลทั้งหมดลงทะเบียนใน `config/source_registry.toml`
- hash และขนาดไฟล์ถูกเขียนลง `outputs/shared/source_inventory.csv` ทุกครั้งที่ build
- ข้อมูลดิบที่ดึงจากเว็บ (`raw_scraped`) และ archive รอบ ก.ย. อยู่นอก repo บนดิสก์อื่นที่เจ้าของเก็บไว้ (เดิม `../HRH_offrepo/`, รายการไฟล์ใน `MANIFEST.csv`)

## 3. ความพร้อมของข้อมูลสำหรับโมดูลถัดไป

| โมดูล | ใช้ได้ตอนนี้ | มีแต่ยังไม่ผ่านการตรวจ | ขาด (ทำให้โมดูลใช้จริงไม่ได้) |
|---|---|---|---|
| ผู้สูงอายุ / ดูแลในชุมชน | โครงสร้างอายุ, ภาระโรครายอายุ | OP ของ รพ.สต. (ถึง 2565), ความครอบคลุมการดูแลประคับประคอง | ภาวะพึ่งพิง/ADL รายอายุ, ข้อมูลการดูแลที่บ้านและผู้ดูแล, เวลาต่อกิจกรรม |
| ไตวาย (ESRD) | CKD 3–5 ที่วินิจฉัย | — | ผู้ป่วยบำบัดตามวิธี อุบัติการณ์ การปลูกถ่าย การเสียชีวิต และเครื่องฟอกกับบุคลากร |
| มะเร็ง | — | ความชุกที่วินิจฉัย (เต้านม ปากมดลูก ปอด) | อุบัติการณ์จากทะเบียนมะเร็งรายตำแหน่ง/อายุ/ระยะ, การรักษา, เครื่องมือและบุคลากร |
| ภาระงาน/FTE | จำนวนคนรายวิชาชีพ | จำนวนคนรายสถานพยาบาล 19 วิชาชีพ | FTE, เวลาทำงาน, มาตรฐานเวลาต่องาน |
| Anchoring เชิงพื้นที่ | ขอบเขตจังหวัด, ระยะเส้นตรง | spc รายสถานพยาบาล | การย้ายรายบุคคลต้นทาง–ปลายทาง, การส่งต่อผู้ป่วย, วันเปิดบริการ |

โมดูลบริการใน Lab รับข้อมูลชุดที่ขาดเหล่านี้ผ่านการอัปโหลดได้แล้ว รวมถึงข้อมูลการส่งต่อ (from_prov, to_prov, share) และผลการคัดกรอง ดู [service_modules.md](service_modules.md)
